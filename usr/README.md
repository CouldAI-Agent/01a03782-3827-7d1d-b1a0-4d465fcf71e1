# Curriculum Vitae App

A responsive Curriculum Vitae (CV) / Resume application built with Flutter.

## Features
- **Responsive Layout:** Adapts beautifully to mobile, tablet, and desktop screens.
- **Header Profile:** Displays a profile picture, name, and professional title.
- **Contact Information:** Clear, accessible contact details.
- **Experience Timeline:** A chronological list of work experience with descriptions.
- **Education Section:** Details academic history.
- **Skills Grid:** A flexible grid showing technical and professional skills.
- **About Me:** A brief professional summary.

## Tech Stack
- Flutter
- Dart

## Setup and Run
1. Ensure you have Flutter installed.
2. Clone the repository.
3. Run `flutter pub get` to fetch dependencies.
4. Run the app using `flutter run` on your preferred device (iOS, Android, Web, Desktop).
